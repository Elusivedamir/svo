# Линия фронта: Командир батальона

Android tactical game prototype built with Godot 4.5.2.

## Версия 0.1

Только полноэкранная стартовая заставка в горизонтальной ориентации: название, стилизованные поля и лесополосы, индикатор подготовки и состояние «ГОТОВО». Главного меню и карты пока нет. Это технический прототип, визуальный стиль ещё не утверждён.

## Сборка через GitHub

После push в ветку `main` автоматически запускается `.github/workflows/android-apk.yml`.
В разделе **Actions → Android APK** открой успешный запуск и скачай **SVO-v0.1-debug** в блоке Artifacts, распакуй ZIP и установи APK.

Это debug-сборка для тестирования, не для Google Play. Пока каждый запуск CI создаёт новый временный ключ подписи: при повторной установке APK с другой подписью Android может потребовать удалить предыдущую тестовую версию. Для следующих версий следует настроить постоянный ключ подписи в GitHub Secrets.
