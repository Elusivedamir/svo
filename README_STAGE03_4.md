# Линия фронта — v0.3.4: береговая линия и читаемость карты

Цель: устранить движение шарика по рекам и улучшить воспринимаемую резкость карты.

## Что менялось
- assets/map/terrain_v0.3.4.png: оригинальная единая утверждённая местность, усилена локальная контрастность и края объектов. Исходное изображение 1672x940, поэтому это **не настоящая 4K-детализация**.
- assets/map/navigation_v0.3.4.png: заменена только разметка воды и мостов, сохранены остальные категории; добавлены полосы береговой безопасности.
- scripts/world_map.gd: ссылки на ресурсы, проверки водных клеток и запрет маршрута с блокированными точками.
- data/map_v0.3.4.json: описание логики и ограничения точности.
- Автоматическая проверка GitHub: запуск, музыка, карта, открытый мост, блокировка воды, маршруты на большой карте.

## Что НЕ менялось
Музыка, меню, заставка, иконка, размер мира 12800×7200, управление камерой, размер тестового шарика и скорость.

## Ограничения
Это ручная разметка по утверждённому изображению. Берега и мосты требуют проверки на настоящем Android, особенно на дальних участках. Изображение не является настоящей 3D-геометрией. Дорожная и строительная разметка всё ещё приблизительная. Новая версия устанавливается после успешной проверки GitHub Actions; прежнюю APK не удаляйте заранее.

## Проверка
Переместить шарик через реку по прямому направлению, убедиться, что он обходит водную преграду и может пересечь только разрешённый мост. Отдельно проверить запрет назначения цели в воде.
