# Линия фронта — v0.5.1: проход по мосту и первый отряд

Патч применяется поверх проверенной v0.4. Он исправляет проход по четвёртому видимому мосту у дорожной развязки со скриншота и включает первый управляемый отряд, подготовленный для v0.5. Используйте этот архив вместо ранее выданного v0.5.

## Исправление моста

На изображении карты мост у развязки был виден, но его настил в навигационной маске оставался водой. В новой маске `assets/map/navigation_v0.5.1.png` ровно 34 перечисленные клетки полотна меняются из WATER в BRIDGE и соединяют оба берега. Вода рядом с мостом остаётся запретной. Все 271 клетка трёх прежних мостов и здания сохраняются.

Исходные изображение карты `terrain_v0.3.4.png` и маска `navigation_v0.3.6.png` остаются без изменения. Новая маска создаётся из старой инструментом `tools/author_bridge_v051.py`; разметка исправленного коридора хранится в `data/bridge_corridors_v0.5.1.json`. Сухой северо-западный проход и расположение объектов сохраняются.

## Управление отрядом

На карте появился один зелёный тактический значок пехоты «ПЕХОТА 1» с перекрещёнными линиями. Отдельные бойцы, бой, здоровье и численность пока не вводятся.

- Отряд выбран при запуске карты. Тап по земле задаёт ему маршрут по навигационной сетке.
- Тап по значку отряда выбирает его и сохраняет текущий маршрут.
- «Снять выбор» убирает выделение. Движущийся отряд продолжает выполнять приказ; тап по земле при снятом выборе не меняет маршрут. Кнопка меняется на «Выбрать отряд» и позволяет выбрать его снова.
- «СТОП» останавливает выбранный движущийся отряд в текущей точке. Кнопка отключена, если отряд не выбран или уже стоит.
- «К ОТРЯДУ» возвращает камеру к нему при любом состоянии выбора, сохраняя масштаб и маршрут.
- Панель показывает «Ожидает приказа», «В пути» или состояние со снятым выбором.

Свайп одним пальцем двигает камеру. Два пальца масштабируют карту и позволяют одновременно двигать её. Отпускание пальцев после жеста не задаёт приказ. Кнопки панели не передают нажатие карте. «Назад» возвращает в прежнее меню.

Графическая обработка, меню, музыка и размер мира 12800×7200 сохраняются. Android version name 0.5.1, code 17.

## Сборка через Termux

Архив содержит 14 новых или изменённых файлов и их контрольные суммы. Нужен полный репозиторий v0.4 в `$HOME/svo`. Сохраните `svo-v0.5.1-bridge-fix.zip` в Download и выполните:

```sh
unzip -o "$HOME/storage/shared/Download/svo-v0.5.1-bridge-fix.zip" -d "$HOME/svo-v0.5.1-patch" && bash "$HOME/svo-v0.5.1-patch/deploy-v0.5.1.sh"
```

Скрипт проверит контрольные суммы, чистое рабочее дерево, отсутствие конфликтующих локальных файлов и точную исходную версию `40763255e8c779127b4d60c742b5b9d1bec1f216`. Сохранит её тегом `stable-v0.4`, применит патч, отправит изменения в GitHub, дождётся проверки и сборки и скачает `SVO-v0.5.1-debug.apk` в `Download/SVO/v0.5.1`.

При повторном запуске уже отправленный v0.5.1 распознаётся по совпадению всех 14 файлов и наличию проверенной v0.4 в истории. Скрипт продолжит ожидание и скачивание сборки именно текущего коммита. Несовпадающая версия, несохранённые изменения, файлы в индексе Git или конфликтующие локальные файлы останавливают применение без сброса репозитория и перезаписи проекта.

Если изменения уже отправлены, готовый APK можно скачать отдельно:

```sh
bash "$HOME/svo-v0.5.1-patch/download-v0.5.1.sh"
```

Используется рабочее подключение Git/gh в Termux; прямая запись из ChatGPT ранее была отклонена GitHub с HTTP 403. APK v0.5.1 готов только после успешной сборки. Отладочный ключ подписи, как раньше, меняется при каждой сборке: Android может потребовать удалить прежнюю тестовую установку перед установкой новой. Сохраните старый APK для отката.

## Проверка

Локально прошли 168 игровых проверок в Godot 4.6.3: 17 исправленного моста, 41 прежней навигации, 52 камеры и 58 отряда/панели. Новый тест на прежней маске выявлял ошибку; на новой все клетки полотна принимают события касания через viewport и GUI, движение в обе стороны проходит через мост без воды или зданий. Закрытие только нового мостового коридора снова разделяет берега. Дополнительно прошли 9 проверок установщика на изолированных Git-репозиториях.

GitHub Actions проверяет размеры новой маски, запускает прежние проверки навигации и камеры, затем проверки отряда `tools/test_squad_v05.gd` и мостового прохода `tools/test_bridge_v051.gd` в Godot 4.5.2 перед экспортом APK. Каждая проверка ограничена 60 секундами; ошибка останавливает сборку. Локальная проверка логики выполняется в headless Godot 4.6.3 и не заменяет проверку на Samsung.

После установки:

1. Задайте маршрут через исправленный мост у развязки со скриншота в обоих направлениях. Отряд должен пройти по настилу.
2. Тапните воду рядом с мостом: приказ через воду не должен выполняться. Проверьте три прежних моста и сухую северо-западную область.
3. Задайте отряду маршрут, снимите выбор и тапните другую точку карты. Отряд должен продолжить исходный маршрут.
4. Выберите отряд тапом по его значку или кнопкой. Новый тап по земле должен изменить приказ; «СТОП» должен остановить его в текущей точке.
5. Масштабируйте и двигайте карту пальцами, нажимайте «К ОТРЯДУ». Выбор и маршрут должны сохраняться. Проверьте возврат в меню и плавность.
