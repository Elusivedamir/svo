# «Линия фронта» — v0.3.1 / карта и тестовый шарик

Патч не заменяет файлы заставки, музыки, настроек или главного меню. Меняются
только `scripts/world_map.gd`, карта и новая маска проходимости, автоматические
проверки GitHub и номер версии Android.

## Управление (Android)

- **Тап по проходимой земле:** шарик сам строит маршрут и идёт к клетке.
- **Тап по дому или мокрому рву:** виден короткий красный круг, шарик остаётся на месте.
- **Провести пальцем:** передвинуть камеру. Шарик остаётся там, где был.
- **Назад:** возврат в главное меню.
- ИНТЕРФЕЙС, блиндажи, бойцы, техника и вооружения пока не добавляются.
- На ПК можно щёлкать и использовать колесо мыши для теста масштаба.

## Реальные правила проверки

Поля, дороги, лесополосы: проходимы; переход по дорогам обычно выгоднее.
Клетки зданий и небольшой водной канавы непроходимы. Единственный разрешённый
переход через тестовую канаву — участок дороги/водопропуск с пометкой «мост».
Используется AStarGrid2D (209×118 ячеек, 8 соседей, запрет срезания углов).
Скорость зависит от типа клетки. Неудачный путь не рисуется «напрямую».

**Ограничения:** визуальный угол около 70° пока запечён в картинке. Это
реалистичная 2.5D-подложка, а не готовая трёхмерная геометрия. Маска размечена
вручную по домам и ландшафту; границы станут точнее с 3D-моделями и
полигональными коллизиями. Мы не выдаём изображение за полноценную физическую
сцену. На карте не требуется видеть сетку: она скрыта.

## Файлы

- `assets/map/terrain_v0.3.1.png` — утверждённая иллюстрация с полями и домами.
- `assets/map/navigation_v0.3.1.png` — машинная маска проходимости по координатам.
- `scripts/world_map.gd` — тестовая сцена, AStarGrid2D, шарик и управление.
- `data/map_v0.3.1.json` — схема координат и правила классов клеток.
- `tools/make_nav_mask.py` — исходник подготовки навигации. НЕ выполняется в APK.
- `.github/workflows/android-apk.yml` — проверка загрузки, музыки, меню, карты,
  непреодолимых препятствий и хотя бы одного построенного маршрута.

## Восстановление

При применении патча перед обновлением создаётся локальный Git тег
`stable-v0.3-before-ball`, сохраняющий предыдущий коммит. Не сбрасывай
репозиторий, пока мы не сравним результат на телефоне.

Артефакт: `SVO-v0.3.1-debug.apk` в `Download/SVO/v0.3.1`.
В GitHub Actions на каждой сборке создаётся временный debug-ключ — Android
может попросить удалить ранее установленную версию для установки нового APK.
