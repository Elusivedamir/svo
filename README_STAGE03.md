# Линия фронта — этап 3 / v0.3

Это первая рабочая карта в существующем Android-проекте Godot 4.5.2.
Никаких игровых сооружений, личного состава, противника, разведывательных маркеров или HUD.

## Что можно проверить

1. Запустить игру, дождаться заставки и попасть в прежнее меню.
2. Нажать **НОВАЯ ИГРА** — появится карта полей, лесополос и грунтовых дорог, строго сверху.
3. Вернуться в меню системной кнопкой «Назад» (или Escape с клавиатуры).
4. Проверить, что музыка, значок, заставка и настройки меню не изменились.

Передвижение карты и масштабирование — **следующий отдельный этап (v0.4)**.
Сохранения и «ПРОДОЛЖИТЬ» остаются недоступны.

## Техническая основа

- `scenes/world_map.tscn` — самостоятельная игровая сцена.
- `scripts/world_map.gd` — Godot Node2D с камерой и переходом назад.
- `assets/map/terrain_v0.3.png` — *оригинальная процедурная подложка* размером 3200×1800, без текста и интерфейса.
- `data/map_v0.3.json` — сведения о зонах полей, лесополосах и дорогах в координатной системе карты.
- `tools/build_terrain.py` — исходный генератор подложки для изменений, Python + NumPy + Pillow + OpenCV. Не нужен для запуска APK.
- Логический размер мира: 6400×3600 единиц. Данные карты и текстура независимы, для будущих объектов и камеры.

Подложка **не спутниковая фотография конкретной территории** и не утверждённый финальный арт. Она предназначена для согласования композиции и дальнейшей разработки сцены.

## Защита от регрессий

GitHub Actions теперь сначала проверяет переход к меню и музыкальный проигрыватель, затем *отдельно запускает сцену карты*. При ошибках GDScript или отсутствии сигнала `SMOKE_MAP_READY` APK не выдаётся.

Экспорт сборки: `SVO-v0.3-debug.apk`, версия Android `0.3.0` (code 8).
Для установки может потребоваться удалить прежний тестовый APK: ключ отладочной подписи пока каждый раз новый.
