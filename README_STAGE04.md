# Линия фронта — v0.4: управление камерой на телефоне

Новый этап поверх проверенной пользователем v0.3.6. Карта, водная маска, сухой северо-западный проход, мосты и графическая обработка сохраняются.

## Управление

- Тап одним пальцем по земле: прежний приказ движения шарика.
- Свайп одним пальцем: перемещение камеры.
- Развести два пальца: приближение; свести — отдаление. Точка карты под центром пальцев сохраняется, пока камера не упирается в границу мира.
- Перемещать два пальца вместе: двигать камеру во время масштабирования.
- После жеста двумя пальцами оставшийся палец может двигать камеру. Его отпускание не задаёт цель шарика. Новый отдельный тап снова задаёт цель.
- **К ШАРИКУ**, справа сверху: вернуть камеру к текущему положению шарика. Масштаб и маршрут сохраняются. На краю мира камера ограничивается границами карты.
- «Назад»: прежний возврат в меню.

Жест, отменённый Android, потеря фокуса приложения, смена размера экрана или нажатие кнопки камеры не превращаются в приказ движения. Учтены третий палец и отпускание пальца над кнопкой: они не оставляют зависшего касания. На ПК колесо мыши масштабирует вокруг указателя, обычный щелчок задаёт движение.

Пределы масштаба сохранены от v0.3.6: минимум заполняет экран картой, максимум равен трём исходным секторным масштабам. На широком экране минимальный масштаб не показывает всю высоту мира одновременно; свайп остаётся доступен. При смене размера экрана масштаб сохраняется относительно размеров viewport.

Меню, музыка, заставка, иконки, расположение объектов, размер мира 12800×7200, скорость и размер шарика не меняются. Персонажи, отряды и бой в этом патче не добавляются. Android version name 0.4.0, code 15.

## Сборка через Termux

Архив содержит только изменённые и новые файлы. Требуется полный репозиторий v0.3.6 в `$HOME/svo`. Сохраните `svo-v0.4-camera-controls.zip` в Download и выполните:

```sh
unzip -o "$HOME/storage/shared/Download/svo-v0.4-camera-controls.zip" -d "$HOME/svo-v0.4-patch" && bash "$HOME/svo-v0.4-patch/deploy-v0.4.sh"
```

Скрипт проверит контрольные суммы, чистое рабочее дерево и базовый коммит `f0102c14d93bfca4ce5d0d9a3f2a97ae200b231c`. Сохранит его тегом `stable-v0.3.6`, применит патч, отправит изменения, дождётся проверок и сборки GitHub Actions и скачает `SVO-v0.4-debug.apk` в `Download/SVO/v0.4`. Несовпадающая версия или несохранённые изменения приводят к остановке без сброса репозитория.

Используется прежнее рабочее подключение Git/gh в Termux; прямую запись из ChatGPT ранее отклонил GitHub с HTTP 403. APK v0.4 не считается готовым до успешной сборки.

Отладочный ключ подписи, как раньше, меняется при каждой сборке. Android может не разрешить обновление поверх предыдущей тестовой установки при несовпадении подписи; прежний APK сохраните для отката.

## Проверка

Локально проверены 52 сценария камеры/жестов и все 41 прежняя проверка навигации/графики в Godot 4.6.3. Девять сценариев используют настоящее прохождение событий через viewport и GUI, включая кнопку и отпускание пальцев над ней.

GitHub запускает ту же проверку камеры и прежнюю проверку навигации в Godot 4.5.2 перед экспортом APK. Каждая ограничена 60 секундами; ошибка останавливает сборку.

После установки на Samsung:

1. Задайте маршрут шарика, затем приблизьте и отдалите карту двумя пальцами. Маршрут должен остаться прежним.
2. Отпустите пальцы в обоих порядках, после жеста проведите оставшимся пальцем: нового приказа быть не должно.
3. Отведите камеру и нажмите «К ШАРИКУ»: камера вернётся, шарик продолжит прежнее движение.
4. Проведите пальцем через кнопку и отпустите над ней. Следующий обычный тап должен работать.
5. Проверьте сухой северо-западный участок, воду, три моста, возврат в меню и плавность на телефоне.

Headless-проверки подтверждают логику и маршрутизацию событий, но не заменяют проверку удобства жестов и реальной плавности на Samsung.
