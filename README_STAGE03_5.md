# Линия фронта — v0.3.5: проверяемая разметка водоёмов

Исправлены две воспроизводимые ошибки v0.3.4: шарик доходил до видимой воды в клетках (28,52) и (395,19), потому что маска считала их полем. Сухой участок (380,39) был ошибочно закрыт как вода.

## Изменения

- Добавлены пропущенные северные заводи и пруды, уточнены основные реки и южные озёра после просмотра всей карты по участкам.
- Удалены ошибочная блокировка сухого участка на северо-востоке, ложный западный рукав и продолжение западной реки поверх сухой местности.
- Разметка состоит из именованных полигонов и каналов в `data/water_regions_v0.3.5.json`. Генератор заменяет только перечисленные проверенные области; вне их прежняя разметка сохраняется. Под убранными водными клетками восстанавливаются предыдущие категории местности.
- Сохранены все 271 клетка трёх ранее проверенных мостовых коридоров.
- GitHub перед экспортом APK запускает `tools/test_navigation_v035.gd`: настоящие назначения цели, движение шарика через три моста, запрет переходов при закрытии мостов, достижимость сухих участков и маршруты между секторами. Проверяются обе прежние водные ошибки и контрольная точка каждого именованного водоёма.

Изображение `terrain_v0.3.4.png` не меняется. Меню, музыка, заставка, значок, размер мира 12800×7200, управление камерой, размер и скорость шарика сохраняются. Версия Android: 0.3.5, code 13.

## Проверка на телефоне

Архив патча не является полным проектом. Прямое обновление из этого чата было отклонено GitHub (`403 Resource not accessible by integration`), поэтому новую сборку ещё нужно запустить через существующий репозиторий в Termux.

Сохраните `svo-v0.3.5-water-fix.zip` в `Download`, затем выполните одну команду:

```sh
unzip -o "$HOME/storage/shared/Download/svo-v0.3.5-water-fix.zip" -d "$HOME/svo-v0.3.5-patch" && bash "$HOME/svo-v0.3.5-patch/deploy-v0.3.5.sh"
```

Скрипт проверит контрольные суммы и чистоту репозитория `$HOME/svo`, подтянет `main` только вперёд и проверит, что это исходная v0.3.4. Сохранит её тегом `stable-v0.3.4`, применит патч, отправит v0.3.5 в GitHub, дождётся встроенных проверок и сборки APK и скачает результат. Если исходная версия отличается или есть незаписанные изменения, скрипт остановится без сброса репозитория. При ошибке прав GitHub на изменение workflow подключение `gh` должно иметь соответствующий доступ.

Скачайте артефакт `SVO-v0.3.5-debug` из успешной сборки GitHub Actions. Распакуйте ZIP и установите `SVO-v0.3.5-debug.apk`. Скрипт `download-v0.3.5.sh` скачивает существующую успешную сборку в `Download/SVO/v0.3.5`, без новой отправки исходников и без запуска повторной сборки.

1. Запустите игру: заставка, музыка, меню и «Новая игра» должны работать как раньше.
2. Проверьте северо-западную заводь и северо-восточный пруд: тап в воду отклоняется.
3. Направьте шарик между берегами возле западного дорожного моста, центрального мостика и восточного дорожного моста: маршрут должен пройти через мост.
4. Проверьте возвращённый сухой участок северо-востока и дальние берега.
5. Вернитесь в меню кнопкой «Назад».

Разметка остаётся вручную подготовленной 2D-маской поверх рисованного изображения. Запас на берегах консервативен; отражения, мелкие водные участки и края под деревьями требуют визуальной проверки на Android. Успешный CI не заменяет проверку Samsung. Шарик использует навигацию центра, а не физическую коллизию всей нарисованной окружности.

Ключ отладочной подписи, как и раньше, создаётся заново при каждой сборке. При несовпадении подписи Android может не разрешить обновление поверх старой тестовой установки; прежний APK сохраните для отката.

## Воспроизведение разметки

В полном репозитории с Pillow и NumPy:

```sh
python tools/author_water_v035.py
godot --headless --path . --editor --quit
godot --headless --audio-driver Dummy --path . --script res://tools/test_navigation_v035.gd
```

Генератор использует неизменённые маски v0.3.3 и v0.3.4, а не уже сгенерированную v0.3.5. Повторный запуск даёт тот же результат.
