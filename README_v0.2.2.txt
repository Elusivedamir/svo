ЛИНИЯ ФРОНТА — v0.2.2 / ЗВУК И НАСТРОЙКИ

ПОЧЕМУ БЫЛО ТИХО:
- Оригинальный музыкальный файл имел средний уровень около -25 дБ.
- Игровой проигрыватель дополнительно уменьшал громкость при воспроизведении.
В v0.2.2 музыка нормализована и запускается на слышимом уровне. Уровень звука
также зависит от Android (громкость МЕДИА, Bluetooth, режим без звука).

ИСПРАВЛЕНО:
1. Меню настроек центрировано; переключатели FPS/эффектов теперь крупные,
   не используют мелкое системное выпадающее меню.
2. FPS: реальный лимит движка 30/60, под переключателем фактический FPS.
   Фактический показатель зависит от устройства и нагрузки.
3. Пыль меню: ВЫКЛ (0), УМЕРЕННО (26), ВЫСОКО (90). Это только эффект меню.
   Графика будущей игровой карты появится в следующих версиях.
4. Громкость управляет Master, есть кнопка ПРОВЕРИТЬ МУЗЫКУ,
   которая перезапускает тему, не меняя утверждённый экран загрузки.
5. Яркость меняет затемнение фона МЕНЮ, не яркость всего Android-экрана.
6. Настройки сохраняются в user://settings.cfg.
7. Заставка и выбранный значок приложения сохранены.

УСТАНОВКА:
cd ~/svo && unzip -o ~/storage/downloads/svo-v0.2.2-fix-settings-music.zip -d . && bash deploy-v0.2.2.sh

После установки: включить громкость МЕДИА на Samsung; открыть НАСТРОЙКИ,
нажать ПРОВЕРИТЬ МУЗЫКУ. Проверь FPS 30/60 и пыль ВЫКЛ/ВЫСОКО.
GitHub Actions собирает debug APK с временным ключом. При отказе обновлять
установленную игру может потребоваться удаление прежней тестовой версии.
