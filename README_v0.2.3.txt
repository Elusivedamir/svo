ЛИНИЯ ФРОНТА — v0.2.3: ВОССТАНОВЛЕНИЕ МЕНЮ

Исправление регрессии v0.2.2 (черный экран после заставки).
- Вернули проверенную ранее реализацию главного меню версии 0.2.1.
- Сохранены утвержденные заставка, фон и иконка приложения.
- Поднята читаемость выпадающих пунктов 30/60 FPS и 0/1/2 эффекта.
- Тема музыки нормализована до ~-17 LUFS, запускается в автозагрузке Godot без дополнительных вызовов из меню.
- Музыка играет непрерывно при смене сцен, общая громкость 0-100% остается.
- Добавлен headless smoke-test настоящего перехода заставка -> меню: CI отклонит APK,
  если меню не запустится или в журнале будут ошибки скриптов.
- Эти графические параметры влияют только на меню: FPS-лимит, 0/16/45 частиц пыли и затемнение фона.
- Удалена кнопка проверки музыки из нестабильной v0.2.2 до восстановления надежности.

Важно: Headless-тест не гарантирует реальную слышимость звука на телефоне.
Подпись на GitHub Actions временная. Android может попросить удалить старую тестовую сборку.
