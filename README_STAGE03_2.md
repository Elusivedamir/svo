# Линия фронта — v0.3.2 / карта в четыре раза больше

Только расширение мира: 6400×3600 → **12800×7200** игровых единиц.
Реальная площадь перемещения ×4. Сетка маршрутов: 209×118 → **418×236** ячеек.
Масштаб одного дома, дерева, дороги и шарика не изменился.

## Что увидишь

- Игра открывается возле прежней точки старта в северо-западном секторе.
- Перемещай карту свайпом вправо/влево и вверх/вниз, чтобы увидеть три новые области.
- Нажатие по местности по-прежнему отправляет тестовый шарик искать путь.
- Дома/вода заблокированы; лесополосы/поля/дороги проходимы; мост разрешён.
- На десктопе колесо мыши позволяет увидеть карту целиком. На Android пока только панорамирование пальцем.

## Что технически изменилось

- `assets/map/terrain_v0.3.2.png`: подложка 3344×1882, четыре смежных сектора с прежним размером деталей.
- `assets/map/navigation_v0.3.2.png`: навигация 418×236, покрывает всё игровое пространство.
- `scripts/world_map.gd`: новые размеры, стартовая камера на прежнем приближении, проверка межсекторных путей.
- `data/map_v0.3.2.json`: размеры четырёх секторов и классификация препятствий.
- `tools/expand_four_sectors.py`: исходник воспроизводимого расширения.
- Автоматическая сборка проверяет PNG, запуск заставки, меню, музыку, препятствия, пути внутри карты и пути между секторами.

### Ограничения текущего прототипа

Три новые области пока **составлены из зеркально отражённых и слегка изменённых по форме областей исходной карты**, а не нарисованы как три неповторимые территории. Это временная честная мера, чтобы сначала проверить масштаб и перемещение. В следующих отдельных патчах можно заменить новые сектора уникальными вручную размеченными локациями, сохранив все координаты и логику навигации.

Настройки музыки и UI остались без изменений. По-прежнему применяются отладочные подписи при сборках APK; Android иногда требует удалить старую тестовую сборку.
